# Primary sources and reading list

Documentation links are for instructor preparation. Software and firmware may change; commands need version-specific validation.

- **GoPro** [Open GoPro docs and HERO10 support matrix](https://gopro.github.io/OpenGoPro/docs/) (official, MIT API); [Python SDK](https://gopro.github.io/OpenGoPro/python_sdk/); [SDK quickstart and `gopro-webcam`](https://gopro.github.io/OpenGoPro/python_sdk/quickstart.html). USB streaming compatibility varies by camera/mode.
- **LeRobot** [SO-101 setup, calibration, teleoperation](https://huggingface.co/docs/lerobot/en/so101); [robot control API](https://huggingface.co/docs/lerobot/main/api/robots); [record/replay tutorial](https://huggingface.co/docs/lerobot/main/en/getting_started_real_world_robot).
- **EV3** [ev3dev2 motors](https://ev3dev-lang.readthedocs.io/projects/python-ev3dev/en/stable/motors.html); [RPyC remote control](https://ev3dev-lang.readthedocs.io/projects/python-ev3dev/en/stable/rpyc.html). RPyC classic only on isolated trusted networks.
- **OpenCV** [Color spaces and `inRange`](https://docs.opencv.org/4.x/df/d9d/tutorial_py_colorspaces.html); [VideoCapture](https://docs.opencv.org/4.x/d8/dfe/classcv_1_1VideoCapture.html).
- **Optional AI** [YOLO-World](https://github.com/AILab-CVC/YOLO-World); [YOLOE](https://github.com/THU-MIG/yoloe). Neither is needed for a color-based beginner workshop.
- **Python learning** [Official Python tutorial](https://docs.python.org/3/tutorial/), particularly conditionals, loops and functions.

Do not redistribute unrelated photos, GoPro SDK binaries, LeRobot models or university logo files without confirming license and rights. This repository contains only its own workshop text and code, with links to external projects.
