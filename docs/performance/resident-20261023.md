Atomic fusion removes 32 full-plane parent copies and 64 transfer barriers: 39,321,600 B copy payload, or 78,643,200 B combined logical device read/write traffic per 640×480 frame. The independent host trace has 71 dispatches, 74 barriers and zero parent copies. Normal upload/compact download remain 1,536,000/163,856 B; explicit correctness diagnostics download 34,570,256 B. Successful native counters report zero hot Vulkan allocations, excluding driver-private allocation.

For a valid monotonically decreasing forest A, frozen B[i]=root(A[i]) satisfies B[i]≤A[i]. Copyback followed by hooks yields min(B[i], hook proposals). Fused connect atomically minimizes A[i] with B[i], then applies the same hooks derived only from immutable B. Unsigned min is associative, commutative and idempotent; the extra initial A[i] cannot change the result. Thus every interleaving has the same per-address round result. Every active in-bounds lane flattens before the boundary early return.

## Paced CPU headroom and delivery

Each old/new/CPU × dense/recorded × host condition ran **3 × 20 seconds**, after 10 warmup frames, with a 4-second start lead, 30 Hz offered arrivals and 2 ms polling. The retained diagnostic uses one active and one replaceable latest pending frame. A separate lightweight 125 Hz integer-control process ran alongside each trial. This diagnostic event model is distinct from the production camera queue.

CLOCK_PROCESS covers the steady perception loop, upload memcpy, submit/poll/finish, compact verification and timestamp overhead. Setup, reference generation, warmup, drain and JSON output are excluded. CPU/frame is aggregate CPU divided by aggregate completed frames; logical CPU demand is CPU divided by wall time. Age p95 is the median of trial p95s. Frames still active/pending at the measurement cut are drained outside measured throughput.

This makes DVFS a plausible contributor, not complete causal proof: there is no matched unpaced frequency trace or per-frame frequency/timestamp join. The monitor can itself affect scheduling/power. This single diagnostic pair does not replace the original three trials; no governor or frequency writes occurred.

The companion compute-only Context had no video capability or enabled robustBufferAccess. Original measured child environments were not saved, so retrospective feature equality cannot be proved. Compute-only results cannot qualify a video-enabled Context without measuring that configuration.

## Latest-frame software boundary

The separately reviewed queue owns one submitted active and one replaceable unsubmitted pending frame within a three-slot lease pool. Active work is never replaced; pending storage is released before acquiring its replacement. Late consumers retain the exact completed slot. Completion/finish/publication precedes pending replacement and dispatch, including ticks with no new arrival.

Both original color/depth IDs must increase. Replaced frames are skipped rather than republished as duplicate 30 Hz output; the policy cannot turn an 80 ms backend into 30 unique completions/s. Original source IDs, hardware timestamps/domains, calibration generation and receipt time survive transfer. Receipt ROS time is sampled immediately after poll, before alignment/copies; receipt age is not device capture age or an independently proven monotonic freshness policy.

The independent 100,000-cycle actual CPU FrameLease queue/formatter microbenchmark measured **143.048 ns/cycle and zero own hot heap allocations**. It excludes Vulkan, camera/SDK work and ROS/RMW/DDS allocation/serialization. It establishes helper cost and ownership only, not full callback or station cost.
